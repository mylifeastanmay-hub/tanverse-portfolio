| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within the Tanverse 3D portfolio ecosystem, please report it directly and responsibly.

### How to report:
1. **Email:** Send details to [tanmayverse776@gmail.com](mailto:tanmayverse776@gmail.com)
2. **Subject line:** `[SECURITY] Tanverse Vulnerability Report - <Brief Description>`
3. **Details to include:**
   - Affected endpoint, component, or file
   - Steps to reproduce or proof-of-concept
   - Impact assessment

Please do not open public GitHub issues for sensitive security vulnerabilities. We will review and address any valid disclosures promptly.
