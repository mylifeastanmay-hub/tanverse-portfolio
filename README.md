## 🚀 Key Architectural Highlights

### 1. Modern Cyber-Timeline (Experience)
* **Responsive Central Neural Spine:** A glowing fiber-optic data bus with animated laser pulse overlays and pulsing glowing nodes at each career milestone.
* **Glassmorphic HUD Cards:** Alternating staggered layout on desktop and streamlined rail on mobile with glowing borders matched to each organization's accent color.
* **Verified Credentials:** Direct display of verification IDs (`CIN: FIT/AUG26/PE3831`) and impact summaries without requiring multiple clicks.
* **Audio Feedback:** Real-time procedural audio synthesis triggers on card hover and modal popup (`playCyberSound`).

### 2. 3D Project Rotating Carousel & Holographic Modals
* Custom 3D deck carousel displaying projects in perspective with spring-physics mouse tilt tracking.
* 18 procedurally engineered high-resolution SVG telemetry and architecture diagrams in `src/assets/projects/`.
* High-visibility metric badges (`⚡ <3ms Latency`, `⚡ P99 <4ms`) and expandable technical breakdowns.

### 3. Interactive Credentials Fan Deck
* Multi-deck fan view grouped by credential issuer.
* Verified certificates from **Google AI**, **Google Cloud Skills Boost**, **Amazon ML Summer School 2026**, **Future Interns** (`CIN: FIT/AUG26/PE3831`), and **ZeTheta Algorithms**.

### 4. Full-Stack Cloud Architecture
* **Dual-Engine Database Layout:** Built-in adapter targeting cloud PostgreSQL with a local SQLite file database fallback.
* **Vercel Blob Integrations:** Ephemeral container storage bypassed by uploading assets directly to Vercel Blob CDN.
* **Cache-Control Protocol:** Strict no-store headers preventing stale API payload caching.

* **Frontend:** React 18, TypeScript, Vite, Three.js, React Three Fiber, Tailwind CSS, Framer Motion

* **Backend API:** Node.js, Express, JWT Authentication
* **Database & Storage:** PostgreSQL, SQLite (Local Dev Fallback), Vercel Blob Storage

## 💻 Local Development Setup

```bash
# 1. Clone repository
git clone https://github.com/mylifeastanmay-hub/tanverse-portfolio.git
cd tanverse-portfolio

# 2. Install client dependencies
npm install

# 3. Start local development server
npm run dev:client
# Local: http://localhost:5174/

# 4. Build for production
npm run build
```
